# 🌐 Personal Portfolio

A modern, responsive portfolio website built to showcase my work, skills, and experience as a software engineer.

---

## 🚀 Overview

This portfolio is designed with performance and simplicity in mind. Built using Vite and React, it delivers fast load times, smooth interactions, and a clean user interface.

---

## ✨ Features

* 🎯 **Hero Section** – Introduction with CTA buttons (Contact & Download CV)
* 👨‍💻 **About Section** – Background, skills, and interests
* 📂 **Projects Section** – Highlighted projects with details
* 💼 **Experience Section** – Work and academic experience
* 💬 **Testimonials Section** – Feedback and recommendations
* 📩 **Contact Section** – Easy way to get in touch

---

## 🛠️ Tech Stack

* **Build Tool:** Vite
* **Frontend:** React, JavaScript
* **Styling:** Tailwind CSS
* **Icons:** Lucide React, React Icons
* **Animations:** CSS & custom animations

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash id="yd1e7s"
git clone https://github.com/your-username/your-portfolio.git
```

### 2. Navigate into the project

```bash id="o2f9xp"
cd your-portfolio
```

### 3. Install dependencies

```bash id="7o9k3v"
npm install
```

### 4. Start development server

```bash id="r3q1zk"
npm run dev
```
